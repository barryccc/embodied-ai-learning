## 七、自检问题答案

1. 训练的**四步**循环是哪四步？
>前向  loss  反向  更新
2. `__init__` 和 `forward` 各干什么？
>init是为了初始化模型，提供可以使用的环境，包括数据类型，模型参数等等
>
>forward是为了往前推进，把输入通过模型进行计算
3. `loss.backward()` 做了什么？
>沿着计算图回退，计算梯度值，算完计算图默认被释放，想要再算得先forward
4. 为什么每轮要 `zero_grad()`？
>因为梯度是累加的 
5. `MSELoss` 和 `CrossEntropyLoss` 分别用在哪？
>mse是预测连续值
>
>交叉熵是分类
6. `lr` 太大 / 太小分别会怎样？
>太大一直震荡可能越来越不准
>
>太小进度太慢数据变化慢
