## 七、自检问题答案

1. `torch.zeros(2,3)` 和 `torch.randn(2,3)` 的区别？
>一个是全零矩阵，一个是随机数
2. `shape` / `dtype` / `device` 分别是什么？
>矩阵形状  数据类型  设备
3. `reshape` 会改变元素吗？
>不会，只改变形状
4. `(3,4) @ (4,5)` 的结果形状？为什么？
>（3，5）
5. 为什么运算前要保证同一个 device？
>不同device无法运算
6. 怎么把一个 tensor 从 CPU 搬到 GPU？
